Минимально для запуска проекта вам понадобится сервер с docker и docker-compose.
Этого достаточно чтобы решение заработало.

Клонируйте на него репозиторий и запустите скрипт install.sh, он:
- запросит у вас пароли для пользователей root и mysql-user в СУБД;
- создаст необходимые для первоначального развёртывания файлы;
- внесёт изменения в файлы настроек для упрощения и дальнейшего использования;
- запустит docker compose up -d для сборки и запуска проекта.

Jenkinsfile добавлены в проект для CI/CD, один для тестового контура, второй
для продуктивного. Для автоматизации настроены джобы, срабатыващие по
GitHub hook trigger for GITScm polling, один для изменений в ветке devel,
второй в ветке main.

С помощью terraform в Yandex Cloud разворачивается система мониторинга нашего
проекта на базе одной ВМ с Prometheus + Grafana в docker compose. 
Данное решение принято исключительно в целях экономии времени и средств,
для продуктивного использования рекомендуется развёртывание в K8s кластере.
Мониторинг мониторинга из облака не обязателен, если у вас уже есть мониторинг
в локальной сети.
